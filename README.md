## 📖 Sobre o Projeto

**Vale O Seu Tempo?** é uma experiência interativa desenvolvida com HTML, CSS e JavaScript puro.

Durante um único dia fictício, o jogador é colocado diante de diversas situações comuns da vida cotidiana e precisa tomar decisões sobre como utilizar seu tempo.

Ao final da experiência, o sistema analisa as escolhas realizadas e apresenta uma reflexão baseada nos comportamentos predominantes.

O objetivo não é julgar o jogador, mas incentivar uma reflexão sobre hábitos, prioridades e o uso consciente do tempo.

---

## 🎮 Como Funciona

O jogo apresenta cinco momentos do dia:

* 🌅 Manhã (06:00)
* ☕ Manhã (10:00)
* 🍽️ Tarde (13:00)
* 🌇 Noite (19:00)
* 🌙 Noite (22:00)

Em cada momento, o jogador escolhe uma entre três opções.

As escolhas são classificadas em categorias:

| Categoria   | Significado                               |
| ----------- | ----------------------------------------- |
| Distração   | Consumo passivo e entretenimento imediato |
| Autocuidado | Bem-estar físico e mental                 |
| Crescimento | Aprendizado e desenvolvimento pessoal     |
| Conexão     | Relações sociais e vínculos               |
| Trabalho    | Produtividade e entregas                  |

Após cada escolha, o jogador recebe um pequeno feedback explicativo.

Ao final, o sistema identifica qual categoria predominou durante o dia e gera uma reflexão personalizada.
